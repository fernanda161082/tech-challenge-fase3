# Notebooks

Notebooks de exploração interativa. O pipeline oficial roda pelos scripts
em `src/`; os notebooks servem para investigar os dados, visualizar
resultados e documentar o raciocínio analítico passo a passo.

| Notebook | Conteúdo |
|---|---|
| `01_analise_exploratoria.ipynb` | Distribuições, correlações e hipóteses que orientaram a modelagem |

Os notebooks leem as bases de `data/processed/`. Rode antes os scripts
de `src/preprocessing/` descritos no README principal.
